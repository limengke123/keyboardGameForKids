# 咚咚键盘 🎹

给小朋友随便敲键盘玩的静态小游戏。按哪个键，屏幕上就蹦出一个**大大的字**，还会用你选的语言把它念出来；数字可以输入 0–100 听发音。配星星、彩纸和一声好听的「咚」。

**在线试玩：** <https://limengke123.github.io/keyboardGameForKids/>

![预览](preview.jpg)

## 开始玩

- **双击 `index.html`** 就能玩——不用安装、不用联网、不用构建。
- 打开就直接是「随便按」模式：**没有开始按钮，也不会自动全屏**。想全屏点右上角 ⛶ 就行。
- 浏览器规定必须先有用户操作才能出声，所以第一次按键 / 点击后才有音效和朗读。
- 也可以整个文件夹丢到任意静态服务器 / GitHub Pages / 内网共享目录。

## 四种玩法

### 🎲 随便按

按任意键 → 全屏巨字 + 糖果色描边 + 星星爆开 + 木琴音。
空格、回车、退格、方向键、Shift、F1–F12 这些特殊键也有中文名字和小表情。
屏幕底部会留下最近按过的 8 个键。

### 🔍 找一找

小兔子说「找一找 B」，按对了撒彩纸、+5 颗星；按错了只有一句温柔的提示，**不扣分、不结束**。
题库去掉了容易看混的 `I`、`O`、`0`、`1`；每题 7 秒没动静，气泡会轻轻晃一下提醒。

### 🎹 小钢琴

每个键对应五声音阶里的一个音，**物理上相邻的键，音高也相邻**，所以随便乱按都好听。
每按一下会扩散一圈彩色涟漪。

### 🔢 数字

按数字键输入 `0–100`，停一下就会用当前语言把整个数字念出来。
`Enter` 或空格再听一遍，`↑ ↓` 加减 1，`Backspace` 删一位，`Delete` / 🧽 清空回到 0。
超过 100 会提示；已经在 100 时再按数字，会当作重新输入。

![数字模式](preview-number.jpg)

## 🗣 按字母 / 数字朗读

按字母或数字时，会用浏览器自带的语音把它念出来（不联网、不下载音频文件）。

右上角 **🌍 EN** 按钮可以切换语言或关掉朗读：

- 中文 / English / Français / Español / Deutsch / 日本語 —— 只列出系统里真的装了语音的语言
- 默认英语；没有英语语音时自动用中文；一个语音都没有时按钮会自动隐藏
- 会自动跳过系统里的搞怪语音（Albert、Eddy、Zarvox 之类），优先 Samantha / Thomas / 婷婷 这类正常声音
- 菜单底部的「声音：Samantha ⇄」可以换一个声音，点一下就会用新声音试听，选择按语言记住
- 菜单既可以用鼠标点，也支持 **方向键 + 回车**（电视遥控器）
- 选择会记在本地；游戏静音时朗读也一起静音
- 小钢琴模式里会先响琴声、再念字母；数字模式会念整个数字

![朗读语言](preview-speech.jpg)

## 🐢 流畅模式（电视 / 旧设备）

右上角有一个「🐢 流畅」按钮，点一下会切换到轻量效果：

- 关掉背景里四团巨大的模糊光斑，换成静态渐变
- 粒子 / 彩纸数量减到约 1/3，扩散粒子减到约 40%
- 去掉巨字的投影滤镜，缩短弹跳动画
- 降低 Canvas 渲染分辨率（4K 屏上省很多填充率）

电视、机顶盒或 `prefers-reduced-motion` 的设备会**自动开启**；也可以随时手动关掉。选择会记在本地。
也可以用 URL 强制：`index.html?lite=1`（省电）或 `index.html?lite=0`（完整效果）。

## 给家长的小提示

- 需要实体键盘；手机 / 平板上打不开输入，只能看到界面。
- 打开即玩，没有开始页，不会自动全屏；右上角 🔊 静音、🌍 朗读语言、🐢 流畅、⛶ 全屏。
- 朗读用的是系统语音，音色和「有没有某种语言」取决于电脑 / 电视装了什么语音包；电视浏览器如果没有语音引擎，「🌍」按钮不会出现。
- 电视上如果显示不正常或动画卡，先点「🐢 流畅」；还不行就换电视自带的另一个浏览器试试。
- 星星和语言选择都存在浏览器本地（`localStorage`），关掉再打开还在。想清零：控制台执行
  `localStorage.removeItem('dongdong.stars')`。
- 网页会拦截空格、方向键、Tab、退格、F1–F10 的默认行为，避免误滚动、误跳转。
- 但 `Cmd+W` / `Ctrl+W` / `Cmd+Q` 这类浏览器和系统快捷键，任何网页都拦不住。
- 中文输入法开着也能识别字母：`e.key` 不可靠时会退回物理键位 `e.code`。
- 全屏时按 `Esc` 会先退出全屏，这是浏览器的行为。

## 文件结构

```
keyboard-kids/
├── index.html
├── preview.jpg
├── preview-speech.jpg
├── preview-number.jpg
├── css/
│   └── style.css      # 布局、糖果配色、动画、流畅模式、朗读菜单
├── js/
│   ├── keymap.js      # 键位 → 字 / 词 / 音高 / 题库
│   ├── audio.js       # Web Audio 现场合成音效
│   ├── speech.js      # 系统语音朗读（Web Speech API）
│   ├── fx.js          # Canvas 星星、彩纸、光圈
│   └── app.js         # 三种玩法、朗读设置、流畅模式
├── .github/workflows/
│   └── sync-pages.yml # main → gh-pages 自动发布
└── README.md
```

零依赖、零构建、零外部请求；字体和语音都来自系统。

## 技术说明

- 单页纯静态，`file://` 直接打开可用：脚本都是普通 `<script>`，没有 ES Module（避免本地打开被 CORS 拦）。
- 音效全部由 Web Audio 现场合成，工程里没有任何音频文件；音高取自五声音阶，所以乱按也和谐。
- 朗读用浏览器内置的 Web Speech API（`speechSynthesis`），同样不联网、不引第三方；朗读时会自动压低按键音。
- 语音会按「语言 + 音色质量」打分：过滤 macOS 的搞怪语音，优先系统里的正常声音，并支持按语言记住手动选择。
- 键盘事件优先读 `e.key`（跟随键盘布局），拿不到时退回 `e.code`（物理键位），并过滤长按产生的 `repeat`。
- 巨字用 JS 测量后自适应，横屏、竖屏、超宽屏、投影仪都不会溢出；窗口缩放会重新排。
- 粒子用一个 canvas + 单个 rAF，粒子落完自动停，不空转。
- **老电视兼容**：没有用 `inset` 简写（改用 `top/right/bottom/left`），关键尺寸都带 `clamp()` 降级值，`100dvh` 放在 `@supports` 里，flex 间距用 margin 而不是 `gap`。
- 支持 `prefers-reduced-motion`，并会自动识别 SmartTV / Tizen / webOS 等 UA。

## 调试

`index.html?demo=1&key=B`：跳过一切，直接模拟按下 B。
其他例子：`?demo=1&mode=find`、`?demo=1&mode=piano&key=G`、`?demo=1&mode=number`、`?demo=1&code=Space`、`?lite=1`。

## 浏览器

Chrome / Edge / Safari / Firefox 近几年的版本；电视浏览器建议用「流畅模式」。
朗读是否可用、有哪些音色，取决于系统语音包。
